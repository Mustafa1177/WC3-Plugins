# WC3-Plugins
plugin/mix files for Warcraaft III v1.26


## Hardware Cursor

The hardware cursor option allows your graphics processing unit (GPU) to draw and render the mouse pointer directly on the screen's frame buffer, independent of the game engine. It delivers a lag-free, responsive cursor movement that matches your monitor's native refresh rate, even if your in-game frame rate drops.

## W3RendererFpsUncap

Removes the 64fps video cap and results in a smooth cursor, camera scrolling, and main menu.
